# 周更内容发布流水线

## 一句话定位
小红书 + 视频号 双平台周更内容生产线，从选题到发布全流程跑顺。

## 当前状态（2026-05-07）
- 节奏：每周二选题会 → 周三周四写稿 → 周五审 → 下周一/三/五发
- 平台：小红书（主战场）+ 视频号（同步分发）
- 团队：内部撰稿 1 人 + 代运营 [李四](../people/_example-小红书代运营对接人.md)（排期/发布）
- 数据：小红书周均阅读 8k-15k，视频号 1k-3k
- 痛点：选题质量波动大，依赖周二会议的临场状态

## 流程
```
周二 10:00  选题会（30 min）→ 锁定 3 篇主题
周三-周四  撰稿（每篇 ~3h）
周五 15:00  内部审稿（标题 / 封面 / 第一段 三关）
下周 周一/三/五 09:00  发布（代运营操作）
发布后 24h  数据复盘（写到周报）
```
