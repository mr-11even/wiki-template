# people/ — 一人一页

**命名**：`{姓名}-{角色/IP}.md`，例如 `张三-同事.md`、`妈妈.md`、`老王-微信群友.md`。

**什么时候建页**：
- 在某个对话 / 项目里这个人被提到超过 2 次
- 这个人的特质/偏好/经历会影响未来的决策
- 你希望下次聊到这个人时 AI 能直接"认识"他

**不建页的情况**：
- 匿名/一次性出现的人
- 纯公共人物（维基能查到的）

**起点问题**（建页时 AI 可以帮你填）：
- 他/她是谁？
- 和我是什么关系？
- 哪些项目/事情涉及他/她？
- 与他/她沟通时要注意什么？
- 这个人身上有什么我可能忘但重要的事？

建好一个页面后，在 `wiki/index.md` 里加一条链接。
