---
description: 在 wiki 里找两个实体/主题的关系路径
argument-hint: "<实体 A> <实体 B>"
---

用户想知道「$1」和「$2」在他的第二大脑里如何关联。

工作流：
1. 读 `{{WIKI_ROOT}}/wiki/index.md` 定位 $1 和 $2 对应的页面
2. 读两边的页面
3. 找**四层关系**：
   - **直接链接**：wiki 里 A 的页面有没有链到 B？反之？
   - **间接节点**：A 和 B 是否通过同一个第三方（人/项目/决策）连接？几步可达？
   - **隐性共现**：raw/ 里有没有 session 同时提到 A 和 B？（用 Grep 扫 summary 和 digest，别全扫 full）
   - **意外 pattern**：A 和 B 虽然没直接链接但思想上有什么相似点？
4. 输出格式：
   ```
   ## $1 ↔ $2 的连接

   **直接**：X 页提到 Y（或"无直接链接"）
   **最短路径**：A → C → D → B，步数 = 3
   **共现**：raw/YYYY-MM/xxx 同时提到（1-3 处）
   **意外观察**：...（AI独立判断，可以没有）
   ```
5. 如果两者**毫无关系**，明确说没有，别硬凑
