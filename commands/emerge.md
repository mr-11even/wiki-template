---

用户要 AI当镜子：找出他自己没明说、但**散落在多处重复出现的 pattern**。

工作流：
1. 读 `{{WIKI_ROOT}}/wiki/` 所有页面的 frontmatter 和首段
2. 扫 `{{WIKI_ROOT}}/raw/digests/` 的所有 digest，特别是"用户的风格"章节
3. 找三类隐性 pattern：
   - **跨项目重复的原话或习惯**：比如"成本敏感"、"不心疼沉没成本"、"业务倒推技术"——哪些他反复说但没集中沉淀？
   - **方法论迁移**：某个 pattern（如"多 AI互为对照"）在某个项目出现了，但 用户自己没意识到可以推广到其他项目？
   - **潜在主题**：多个项目都提到但没成 wiki 主页的概念（如"Max 订阅额度作为战略资源"、"实战验证>理论"）
4. 输出格式：
   ```
   ## 浮出的 Pattern（3-5 条）

   ### 1. {Pattern 名}
   **出处**：在 X 项目、Y 项目、Z 决策里反复出现
   **证据**：具体引用 2-3 条
   **潜台词**：用户其实在说 {深层意图}
   **建议**：是否该写成 wiki 的一个独立页（/ about-me 增补 / ideas-backlog 新项目）

   ### 2. ...
   ```
5. 不要虚，每条必须有**具体出处**。编不出来的 pattern 就不要写。
