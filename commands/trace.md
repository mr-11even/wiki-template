description: 追溯某想法/决策/项目在 wiki+raw 里的演化轨迹
argument-hint: "<想法/主题/项目名>"
---

用户要追溯「$ARGUMENTS」在他的第二大脑里的演化轨迹。

工作流：
1. 全文搜 `{{WIKI_ROOT}}/wiki/` 找出现过 $ARGUMENTS 的页面，记录每个文件的 `updated` 日期
2. 全文搜 `{{WIKI_ROOT}}/raw/` 的 summary 和 digests（不要读 full 避免爆上下文）找时间戳
3. 如需要具体原话，再定向翻对应的 `raw/transcripts/`
4. 按时间顺序**构建一条演化时间线**：
   - 最早出现：什么场景下冒出来的？
   - 中间转折：几个关键节点 用户怎么改变了看法？
   - 当前状态：wiki 最新页面是怎么说的？
   - 矛盾/反复：有没有 用户自己前后打架的地方？
5. 输出格式：
   ```
   ## $ARGUMENTS 的演化轨迹
   - YYYY-MM-DD · 初现：xxx（引用）
   - YYYY-MM-DD · 转折：xxx（引用）
   - ...
   - 当前状态：xxx
   ```
6. 最后一段独立写：**AI的观察**——这条轨迹里 用户可能自己没看出来的 pattern

不要列长段原文。每个节点一两句话。引用位置（文件名:行号）。
